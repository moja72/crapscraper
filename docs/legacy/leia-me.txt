autoscraper/

│  ├─ adapters/

│  │  └─ handlers.py                -> rotas GET/POST
│  │
│  ├─ ui/
│  │  ├─ page_monitor.py            -> HTML da tela
│  │  ├─ styles.css                 -> CSS separado
│  │  └─ app.js                     -> JS separado
│  │
│  └─ shared/
│     ├─ utils.py                   -> helpers genéricos
│     └─ urls.py                    -> helpers de URL
│
├─ data/

└─ logs/                            -> logs gerais do app
